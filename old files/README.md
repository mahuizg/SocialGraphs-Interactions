(`../pipeline_final/`), and nothing outside this folder reads from it.

| File / folder | What it is |
|---|---|
| `project/` | first version of the data collection (Wikidata, Wikipedia, OpenAlex) and cleaning, replaced by `../data_collection/` |
| `who_gets_remembered.ipynb` | single-notebook version of the original analysis (`../data_collection/`), replaced by `../pipeline_final/notebooks/` |
| `validation_and_defence.ipynb` | match-check notebook and oral-defence preparation; reads `data_collection/` and `pipeline_final/` |
| `EXPLICACAO_CODIGO.tex`, `EXPLICACAO_CODIGO_EN.pdf` | internal explanation of the code for the group |
| `pipeline_revised.tar.gz` | archive snapshot of `../pipeline_final/` (from when it was called `pipeline_revised/`) |
| `pipeline_junk/` | an empty `.Rhistory` and a Word lock file (`~$at_we_did.docx`) that were in `data_collection/docs/` |
